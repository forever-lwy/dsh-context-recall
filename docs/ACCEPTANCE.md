# 安装后手工验收

适用版本：dsh `0.2.1-rc.5`，插件 `0.1.0`。
本流程由用户主动安装版本后执行，开发脚本不会自动操作常用实例。

1. 在插件管理器安装 `/plugins/releases/dsh-context-recall-0.1.0.tgz` 并启用。
   按实际界面的加载状态判断是否需要重启。
2. 打开“设置 → 上下文压缩与回忆”，确认可读写、模型目录存在。
3. 选择一个 dsh 已配置的压缩模型并保存；刷新页面确认选择保留。
4. 输入在线向量服务地址、模型和密钥，点击测试。确认返回实际维度；
   启用在线向量后保存，再次打开页面只显示密钥配置状态。
5. 建立包含几个明确决定的测试会话；用原生界面发起压缩或 `/compact`。
   确认摘要调用使用选择的全局模型，随后对话可继续且工具调用正常。
6. 要求模型回忆被压缩前的准确细节；确认当前会话召回和原文下钻正常，
   界面显示简洁的回忆状态行。
7. 明确请求查询同工作区其他会话和跨项目历史，分别验证 workspace/all 范围。
8. 临时填写不可达的向量服务，验证测试失败信息不含密钥，模糊/全文检索仍能工作。
9. 在两个窗口同时编辑：窗口 A 保存后，窗口 B 的过期保存应提示重新读取，保留其编辑。
10. 恢复正确向量配置。修改模型或维度后，确认旧向量自动失效，重建期间本地检索仍可用。

仍需真实联调确认的因素：所选服务的模型容量、输入限制、embedding 方言、配额、网络与实际浏览器体验。
